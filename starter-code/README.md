# Starter code

Students create the application structure during the setup microlessons rather than cloning a large prebuilt project.

At the end of setup, their repository should contain:

```text
atelier-crm/
├── back-end/
│   ├── .venv/
│   ├── config/
│   ├── crm/
│   ├── manage.py
│   └── requirements.txt
└── front-end/
    ├── src/
    ├── package.json
    └── vite.config.js
```

The completed reference implementation is in `../solution-code`.
