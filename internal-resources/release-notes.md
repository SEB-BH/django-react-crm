# Release Notes

## 1.0.0

- Reframed the Django/React project around a practical CRM workflow.
- Added MERN-to-Django comparisons throughout the module.
- Uses a single Django `crm` app with Contact, Opportunity, and Interaction models.
- Uses Django REST Framework function-based views before introducing authentication.
- Added a React pipeline, interaction timeline, dashboard metrics, and communication shortcuts.
- Added Simple JWT as the final security layer.
- Added completed backend and frontend solution code.
- Added instructor pacing, troubleshooting notes, and explicit scope guardrails.
